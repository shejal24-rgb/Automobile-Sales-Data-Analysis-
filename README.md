## 📌 About the Project

This project explores automobile sales data using Python and popular data analysis libraries. It focuses on understanding vehicle sales, revenue performance, fuel-type preferences, city-wise results, and monthly revenue trends through clear visualizations.

**Project type:** Data Analysis
**Day:** 15 of my Data Analysis Project Series
**Dataset:** Sample automobile sales data

## 🎯 Project Goals

- Calculate total units sold and overall revenue.
- Compare sales performance across automobile brands.
- Explore sales by fuel type.
- Identify city-wise revenue patterns.
- Track monthly revenue trends.
- Understand vehicle price distribution.
- Present insights through informative charts.

## 🗃️ Dataset Overview

The dataset includes the following fields:

- `Sale_ID` — Unique sale identifier
- `Date` — Sale date
- `Brand` — Automobile brand
- `Model` — Vehicle model
- `Vehicle_Type` — Vehicle category
- `Fuel_Type` — Petrol, Diesel, CNG, or Electric
- `City` — City associated with the sale
- `Units_Sold` — Number of vehicles sold
- `Unit_Price` — Price per vehicle
- `Customer_Type` — Individual, Corporate, or Fleet

> **Data note:** The included dataset is sample data for educational and portfolio purposes, not official automobile sales statistics.
